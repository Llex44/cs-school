You just found the basic gates

Each box is a logic gate: a tiny rule that takes true/false inputs and gives one true/false answer. Computers call on true and off false. In code, a question like total >= 30 works like a switch: the data flips it.

GateTrue when…In JavaScriptAt Rosie's Bakery
ANDboth inputs are truea && bisOpen && inZone: we can deliver now

NOTits input is false!a!soldOut: show the Order button

Every decision in software, from "show the checkout button" to "is this password right", is built by combining these. When an AI writes if (…), it's wiring gates together.

Under the hood: how gates add numbers optional

Computers store numbers in binary, using only 1s and 0s. Adding two single digits needs just two gates: XOR gives the digit you write down, and AND tells you whether to carry. Flip the bits and check.

Sum digit (A XOR B)
Carry (A AND B)

Chain these for every digit and you can add any two numbers. Loop two gates back into each other and they hold their answer after the input goes away: that's one bit of memory. A modern chip has billions of gates, built from tiny switches called transistors.

Why the computer read it that way

Code has an order of operations, just like math. In math, × goes before +. In code, && goes before ||. So the AI's line was read as "members, or big orders in the zone". Cleo is a member, so the zone never mattered.

In math2 + 3 × 4 = 14Not 20. The × happens first.
In codem || t && zThe && happens first. Parentheses change the order.

This kind of bug is easy to write and hard to see, for people and AI alike. The code looks like the sentence. Two habits catch it: ask for parentheses whenever a condition mixes && and ||, and test the combinations. Three true/false inputs have 8 combinations. Six have 64. That's why a table of cases beats reading the code.

Under the hood: De Morgan's laws optional

A sign says "No food or drinks." That means no food and no drinks. When you push a NOT inside parentheses, every OR flips to AND (and every AND flips to OR). This is De Morgan's law, and "simplifying" it wrong is a classic AI slip.

The first two tables match on every row, so they're the same rule. The third looks similar but disagrees in the red rows: it would let in someone with food but no drink.
